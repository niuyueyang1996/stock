# 9 维度三级执行手册（V2 · 债当现金 · 金额加权 · 三源对齐 · 不预设剧本）

> 本文件是 `SKILL.md` 的逐维展开。每一维按「指标公式 / 取数口径 / 阈值 / 判据话术 / 图表规格」五列落地，执行时逐条兑现，不跳维。禁止用笔数代替金额、禁止把债与股1:1混算、禁止预设行为模板。

## D1 金额与仓位真相（个人账户资金，非市场资金流）

**D1.1 单笔金额分布**
- 指标：买/卖各自的均值/P50/P90/最大/标准差/偏度；分档占比 `<1k / 1-3k / 3-10k / 10-30k / 30-100k / >100k`
- 口径：`abs(成交金额)`，剔除 GC/银证/股息等非证券流水
- 阈值：P50<3k 且 P90<10k → 网格试盘型；P90>30k 且笔数<50 → 少量重仓型
- 话术：`典型单笔约X元（P50），90%单笔<X元，最大单笔X元，占总市值X%`
- 图表：直方图（6档）+ 箱线图（买/卖对比），金额对数轴

**D1.2 单笔/总市值比（核心）**
- 公式：`单笔占比 = 单笔额 / 当日估算总持仓`
- 估算：优先用累计净入金+累计已实现盈亏+浮盈回推；退化可用期末总市值(表内汇总)锚定
- 分档：<1% 试盘、1-3% 标准、3-8% 重仓、>8% 梭哈
- 话术：`中位数占比X%，P90占比X%，>5%的关键决策共N笔（列出日期/标的/金额）`
- 图表：时间×占比散点，>5%标红，大于8%加标注

**D1.3 资金强度时间序列（个人账户）**
- 指标：日/周/月 `买额/卖额/净额(买-卖)/净额强度(净额/总额)` —— 这是账户资金，不是市场资金流
- 方法：20日滚动净额，识别连续≥5日同向为趋势段（持续加仓/减仓），单日脉冲另标
- 图表：双轴图（柱=买/卖额，线=滚动净额），背景色区分加/减仓段

**D1.4 周转率与资金利用率**
- 公式：`年周转率 = 年买卖总额 / 年均持仓`；`换手率 = 年卖出额 / 年均持仓`
- 口径：分子分母按池分开算（见 D3），全池周转用波动加权（现金×0.1），避免债稀释
- 阈值：<1x 低频、1-3x 适中、>5x 高频穿梭
- 结合 GC占比：`GC拆出额 / 年买卖总额` >30% → 大量闲置现金，非满仓
- 图表：年度周转柱状（分池+加权）+ GC占比叠加

**D1.5 充值/提现节律（个人账户）**
- 指标：银证净入金累计曲线 vs 场内净买额累计曲线
- 话术：`越赚越加钱型 / 固定本金内腾挪型 / 阶段性充值型`
- 图表：双线叠加，标注大额充值/提现点

## D2 形态类型学（6-8 原型坐标落位，不硬分类）

**D2.1 集中度（分池）**
- 指标：`HHI = Σ(仓位占比²)`、`Top3/Top5占比`、`Gini` —— 必须同时报告「风险池HHI」与「全池HHI」，全池仅作参考，定性以风险池为准
- 阈值：HHI>0.25 或 Top3>50% → 极集中；HHI>0.15 → 集中；HHI<0.10 且 持仓>15 → 分散
- 图表：持仓占比树图 / 饼图（Top5+其他），分池双饼对比

**D2.2 广度与重叠（分池）**
- 指标：季度风险池持仓只数、季度间 `Jaccard = 交集/并集`（风险池内）
- 阈值：重叠<30% 穿梭、30-60% 轮动、>60% 核心稳定
- 图表：季度只数折线（分池）+ 重叠率热力图

**D2.3 行业/风格/市值三切面**
- 切面：申万一级行业、红利/成长/周期/金融/债、大小盘（按市值或指数归属）
- 口径：现金池不计入行业分布，单独为「现金管理」
- 图表：桑基图（季度迁移）+ 风格占比堆叠面积图（风险池）

**D2.4 6-8 原型坐标落位（不硬贴标签，给坐标+置信度）**

| 原型 | HHI(风险池) | 只数(风险池) | 重叠率 | 周转(风险池) | 一句话 |
|---|---|---|---|---|---|
| 超市分散型 | <0.08 | >15 | 任意 | 中 | 什么都买一点，行业>8个 |
| 哑铃压舱型 | 中 | 股+债各占比>30% | 中 | 低 | 风险+现金两端，压舱明显 |
| 单股穿梭型 | 高 | <5 | <30% | >3x | 1-2只来回做，高速轮换 |
| 核心-卫星型 | 0.10-0.20 | 6-15 | 40-70% | 中-高 | 3-5只长期底仓+外围轮动 |
| 轮动猎手型 | 中 | 8-20 | 30-50% | >2x | 高频换仓，行业轮动快 |
| 躺平收租型 | 高 | 3-8 | >60% | <1x | 少量红利/债，长期持有 |
| 网格机器型 | 低-中 | 5-15 | 中 | >3x | 小额高频，买卖比>2:1 |
| 梭哈型 | >0.25 | <4 | 低 | 低-中 | 单笔占比>8%，集中押注 |

- 方法：在 `HHI×重叠率×周转` 三轴中打点，取最近原型为主标签，次近为副标签，报告坐标与距离
- 话术：`主型「核心-卫星型」· 副型「哑铃压舱」· 置信度X% · 坐标(HHI 0.12, 重叠31%, 周转2.1x)`

## D3 资金流三态（按池 · 债当现金 · 金额加权）

**D3.1 分池定义**
- 风险池：股票 + 宽基/行业ETF（如 510300、515080）
- 现金池：债ETF（511xxx/159xxx）+ 货币/短融（511620/511360），511360 短融按货币
- 判定：按 `config.yaml:pool` 前缀/代码/名称匹配

**D3.2 日三态（按池净额，不按全池净额）**
- `风险池日净额 = 风险池卖额 - 风险池买额`；`现金池日净额` 同理
- 映射：
  - 风险池内 既买又卖 且 `|净额|/总额<30%` 且买卖各>20% → **真换仓**（风险敞口不变）
  - 现金池→风险池（卖债买股，现金净卖、风险净买）→ **加仓**（风险敞口↑）
  - 风险池→现金池（卖股买债）→ **减仓**（风险敞口↓）
  - 单池内净买>30% → 加仓；净卖>30% → 减仓
- 金额加权：`当日换仓额 = min(风险池卖额, 风险池买额)`；`换仓强度 = 换仓额/风险池总额`
- 图表：三态日历热力图（绿加仓/黄真换仓/红减仓），债→股加仓用虚线边框高亮

**D3.3 连续性**
- 3日同向滑动窗口判趋势段：连续3日加仓=持续加仓期（风险敞口↑）
- 输出：趋势段起止 + 持续天数 + 累计风险池净额

**D3.4 场内外联动**
- 银证净入金 vs 风险池净买额 散点，象限解读：场外加钱加仓 / 场内腾挪 / 获利提现
- 图表：散点+象限标注

**D3.5 交付**
- 月度三态金额占比（风险池）饼图 + 金额条形图；现金池单独为「现金管理」条

## D4 换仓指纹（金额加权 · 不只笔数胜率）

**D4.1 换仓对挖掘（按金额，不按次数）**
- 成对：同日/次日 卖A→买B
- 排序：**按累计换仓额**（Σ min(卖额,买额)）排序，禁止按次数
- 指标：累计换仓额、换仓金额占比（换仓额/风险池买卖总额）、平均换仓额
- 图表：换仓弦图（弦宽=金额）/ Top10 表格（金额列在前，次数仅作括号标注）

**D4.2 动机三源分类（每笔换仓，0/1 打分）**
- 技术源：卖出标的近20日是否弱于买入标的>5% 或破20日均线（get_kline as_of）
- 市场资金流源：卖出标的是否资金净流出、买入标的是否净流入（get_fundflow / get_index_fundflow as_of）
- 基本面源：两标的换仓时点 PE/PB/股息率分位差（get_stock_detail as_of），判高估换低估 / 追强势 / 无差别
- 方法：三源各打0/1，组合成8类动机

**D4.3 合理性五维打分（0-10分，金额加权）**
- 估值差分、动量差分、资金流差分、分散改善（行业HHI下降）、集中度改善
- 加权雷达图，自动标「合理换仓」(≥7分) vs 「情绪化换仓」(≤4分，如低位割肉追高)；权重由数据定，不写死

**D4.4 有效性（金额加权）**
- 换入后20/60日超额 vs 换出后表现；金额加权换仓胜率 + 平均超额
- 图表：换仓有效性散点（x=估值差分, y=后续超额，点大小=换仓额）

**D4.5 单日“低位割”鉴别**
- 对卖点为低分位（<20%）且亏损的换仓，检查同日是否等额买入：净额强度<30%为换仓驱动，>30%为真割

## D5 买卖点三源对齐（逐笔对齐当天快照）

> 核心：每笔 `ds + code + price` 通过 `as_of=ds` 对齐当天三源快照，不拿当前估值套历史交易。

**D5.1 对齐计划（见 references/mcp-plan.md）**
- Top N（持仓Top5 + 换仓高频Top3 + 归因Top3，去重约12）全量逐笔对齐；其余抽样
- 技术：`get_kline` → 当天分位 + 买前5/20日涨跌
- 市场资金流：`get_fundflow(as_of)` / `get_index_fundflow` → 主力净流入强度
- 基本面：`get_stock_detail(partial, as_of)` → PE/PB/股息率分位
- 覆盖率：报告需显式 `K线 X/Y · 估值 X/Y · 资金流 X/Y`，<60% 标样本不足

**D5.2 技术分位**
- 日内分位 = (成交价-当日最低)/(最高-最低)；波段分位 = (成交价-近20日最低)/(20日最高-最低)
- 方向 = 买前5/20日累积涨跌（连续值，不贴标签）
- 图表：买点分位直方图（0-100%）、方向箱线图

**D5.3 资金流与估值锚**
- 资金流：流入强度分档（大额流入/中性/流出）
- 估值：低估（PE<30%分位）、合理、泡沫（PE>80%分位）
- 图表：三源锚定度雷达 + 估值分位 vs 技术分位 散点

**D5.4 卖点与速度轴**
- 止盈(盈利>10%且高分位卖)、止损(亏损且低分位卖)、换仓驱动(同日有买入)
- 纪律：亏损-5%/-10%/-20%卖出率 + 平均亏损持有天数
- 速度轴：持有天数（快<7天 / 中7-30天 / 慢>60天）与追涨内部的快杀 vs 扛单分群
- 图表：卖点类型饼图 + 速度分布

**D5.5 K线标注**
- 重点标的每只一页K线，买卖点大小=金额（非笔数）、颜色=盈亏(红赚绿亏)、箭头=方向

## D6 阶段演进（多维行为向量变点，不预设剧本）

**D6.1 多维行为向量（周度滚动）**
- 技术：方向（买前20日涨跌滚动均值）、位置（20日分位滚动均值）
- 市场资金流：资金流锚定度（买入标的资金流入占比滚动均值）
- 基本面：估值锚定度（低估买入占比滚动均值）
- 节奏/纪律：周转率、单笔P50、换仓率(金额加权)、持有周期、速度（亏损割肉天数）
- 共 8-9 维，不预设哪条会突变

**D6.2 变点检测**
- 方法：多维 PELT（惩罚项 BIC），最多3个变点，敏感性测试±20%惩罚项
- 输出：变点日期+置信度+主导突变维度；不稳定则降级为趋势描述

**D6.3 阶段定性命名（由聚类生成，不查表）**
- 对变点间段的向量均值做聚类，自动生成描述，如「深度逆势+低位+长持」「顺势高位+快进快出」而非查固定表
- 每阶段卡片：起止、主导维度、向量均值、代表交易、关键转折事件

**D6.4 习惯变迁对比**
- 表格：阶段间对比 单笔金额/换仓率/方向/位置/资金流锚定/估值偏好/行业偏好 的变化
- 图表：多维变点时间轴，每段背景色不同，标注主导突变轴

## D7 金额加权归因

**D7.1 贡献分解**
- 金额加权贡献 = Σ每笔已实现盈亏；Brinson（择时 vs 选股）可选
- 对比：金额加权Top5 vs 笔数Top5 的差异（常完全不同，必须并列展示）
- 图表：瀑布图（贡献分解，金额加权）

**D7.2 大单小单分化**
- 按单笔金额三分位，对比胜率/盈亏比/持仓周期
- 话术：`小单胜率X%但贡献仅Y%，大单胜率X%贡献Y%，呈「小单练手、大单定胜负」/「大小单无差异」`

**D7.3 周期归因**
- 持仓时长分档 `<7 / 7-30 / 30-90 / >90天` 的金额加权收益率
- 图表：周期-收益柱状（金额加权）

## D8 纪律与风险（含速度轴）

**D8.1 摊薄深度**
- 单标的最大补仓次数、最大回撤档位（-10%/-20%/-30%仍加仓的比例）
- 图表：摊薄深度箱线图

**D8.2 止损纪律（含速度轴）**
- 亏损阈值卖出率 + 平均亏损持有天数（速度轴：快杀 vs 扛单分群）
- 处置效应：`盈利卖出率 / 亏损卖出率`（>1 显著处置效应）

**D8.3 沉淀成本**
- 单票资金占用时长 vs 同期大盘涨幅（机会成本）
- 表格：沉淀Top5（占用金额×天数，金额加权）

**D8.4 行为偏差**
- 锚定：是否总买回卖出价±2%附近
- 图表：偏差雷达

## 质量门槛

- 金额口径偏差>2%告警
- K线/估值/资金流覆盖率 <60% 时 D5 标注「样本不足」
- 风险池 HHI 必须与全池 HHI 同时报告
- 变点敏感性不稳定则降级
- 报告前跑 `validate_report.py`
