# 报告大纲与视觉规范（V3 · 金额绝对化 · 名称化 · 深度评测）

## 章节（固定9章，债当现金分池；每章 1主图+N深度块+1深度结论段，篇幅不设限）

0. 封面：标题/报告期/风险池市值+现金池市值/累计盈亏/胜率 三指标卡片（分池双值）+ **口径卡**（金额加权 / 债×0.1 波动加权 / 清仓不删缓存 / GC与银证已剔）+ **金额口径声明**（“笔数 vs 金额”必对照）
1. 画像总括（D9）：6-8原型坐标 + 五轴雷达（金额加权）+ 一段话画像（主/副型）+ 优势/盲区卡片（每条配 名称(code)+日期+金额+占总额比）
2. 金额真相（D1）：主图 6档直方图（笔数占比 vs 金额占比双轴，揭示“高频小额”陷阱）+ 深度块：单笔/总市值比散点（点径=金额，>5%标红>8%加注）+ 20日滚动净额（柱=买/卖额，线=滚动净额，段内标累计净额/强度）+ 充值节律双线（银证累计 vs 场内净买，标大额充值/提现点）
3. 形态演进（D2）：主图 风险池 HHI/只数/重叠率三线 + 现金池单条 + 深度块：行业桑基（风险池，季度期数不足时退化为期末截面+文字）+ 风格堆叠
4. 资金流三态（D3）：主图 按池三态日历（格内显金额/强度，绿加仓/黄真换仓/红减仓，债→股虚线边框）+ 深度块：**三态金额占比 vs 天数占比对照表**（揭示次数陷阱）+ 月度占比 + 银证场内外联动散点（象限解读）
5. 换仓指纹（D4）：主图 弦图（弦宽=金额，悬浮显名称）+ 深度块：Top10 表（列：卖出标的**名称(code)** / 买入标的**名称(code)** / 累计换仓额 / **占换仓总额比** / **占风险池总额比** / 行业迁移；Top3 配一句话迁移解读）+ 三源动机8类占比 + 五维合理性雷达（7分合理/≤4情绪）+ 有效性散点（x=估值差分 y=后续超额 点径=金额）+ 低位割标记表
6. 买卖点三源对齐（D5）：主图 三源锚定雷达（金额加权）+ 深度块：日内/波段分位直方图（分箱金额占比）+ 方向箱线（点径=金额）+ 重点标的K线**每只一页**（点径=金额，标题与标注一律 名称(code)）+ 覆盖率水印（K线/估值/资金流 <60% 标样本不足）
7. 阶段演进（D6）：主图 多维变点时间轴（标注主导突变轴）+ 深度块：阶段卡片（起止/主导维度/向量均值/代表交易 名称(code)+金额/关键事件）+ 习惯变迁对照表（单笔金额/换仓率/方向/位置/资金流锚/估值偏好/行业）
8. 归因（D7）：主图 金额加权瀑布（标的标签 名称(code)）+ 深度块：大小单三分位对照（**笔数 vs 金额并列**，话术“小单笔数占比 vs 金额占比”揭示差异）+ 周期分档柱（<7/7-30/30-90/>90天，金额加权）
9. 纪律与风险（D8）：四卡片扩为带 **金额×天数** 的沉淀Top5 + 回撤档位（-10/-20/-30 仍加仓比例，金额加权）+ 止损纪律（亏损阈值卖出率+平均亏损持有天数，速度轴分群）+ 处置效应精确值 + 锚定偏差检验
附录：方法与阈值（config.yaml 摘要，含分池清单与波动权重）+ 新增 **“笔数 vs 金额陷阱对照说明”** + 口径说明（风险池/现金池/全池）+ **名称缺失映射表**（未命中标 *）

## 视觉

- 配色见 `palette.md`，图表同一色板，打印浅色友好
- 风险池用实线/实色，现金池用虚线/浅色，债→股加仓用虚线边框高亮
- 字体：标题 18-20px / 正文 12-13px / 标注 10px
- 每章主图下方 1 结论句 + 每深度块 1 小结论（20-30字粗体），结论均带金额证据
- **用户可见单元一律 `名称(code)`，表头显“标的”而非“代码”**；未命中名称回退为码并标 `*`，附录列映射
- 点径/弦宽/柱宽等视觉通道一律映射**金额**，非笔数
- 模板：`assets/report_template.html`，用 `build_report.py` 注入 `metrics.json`
- 导出：Chrome headless `printToPDF`，A4，页边距 16mm，页眉页脚含页码与生成时间
