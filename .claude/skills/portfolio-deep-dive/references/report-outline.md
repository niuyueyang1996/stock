# 报告大纲与视觉规范（V2）

## 章节（固定9章，每章一主图+一结论句，债当现金分池展示）

0. 封面：标题/报告期/风险池市值+现金池市值/累计盈亏/胜率 三指标卡片（分池双值）
1. 画像总括（D9）：6-8原型坐标 + 五轴雷达（金额加权）+ 一段话画像（主/副型）+ 优势/盲区卡片
2. 金额真相（D1）：单笔分布直方图（分池）+ 占比散点 + 周转时间轴（风险池+波动加权）
3. 形态演进（D2）：风险池 HHI/只数/重叠率三线 + 现金池单条 + 行业桑基（风险池）
4. 资金流三态（D3）：按池三态日历（风险池真换仓/债→股加仓/股→债减仓分色）+ 月度占比 + 银证叠加
5. 换仓指纹（D4）：弦图（弦宽=金额）/ Top10表（按累计换仓额，不按次数）+ 五维雷达 + 有效性散点（点大小=金额）
6. 买卖点三源对齐（D5）：技术/资金流/基本面三源锚定度雷达 + 重点标的K线标注（每只一页，点大小=金额）+ 覆盖率水印
7. 阶段演进（D6）：多维变点时间轴（标注主导突变轴）+ 阶段卡片（聚类生成描述，非查表）+ 习惯变迁对比表
8. 归因（D7）：金额加权瀑布 + 大小单分化（金额加权）+ 周期收益
9. 纪律与风险（D8）：摊薄/止损/沉淀/偏差四卡片（含速度轴：快杀 vs 扛单）
附录：方法与阈值（config.yaml 摘要，含分池清单与波动权重）+ 口径说明（风险池/现金池/全池）

## 视觉

- 配色见 `palette.md`，图表同一色板，打印浅色友好
- 风险池用实线/实色，现金池用虚线/浅色，债→股加仓用虚线边框高亮
- 字体：标题 18-20px / 正文 12-13px / 标注 10px
- 每章结论句为 20-30 字粗体，置于主图下方
- 模板：`assets/report_template.html`，用 `build_report.py` 注入 `metrics.json`
- 导出：Chrome headless `printToPDF`，A4，页边距 16mm，页眉页脚含页码与生成时间
