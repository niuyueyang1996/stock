# 个人自建 ETF 持仓分析

把自己的一篮子 A 股持仓当成一个「自建 ETF」来整体分析与拆分分析：录入持仓、每天记录买卖、自动更新移动加权成本、对每日操作做合理性评分，并展示单股估值分位、资金流、财务与组合的综合 PE/PB、股息率、ROE、增长率、波动率。

> 本期仅支持 A 股。数据全部来自 akshare（新浪 / 百度源），东财行情接口因网络不可达已放弃。

## 功能清单

**持仓与交易**
- 批量初始化持仓，按买卖记录自动更新数量与**移动加权平均成本**（费用计入成本）
- 交易增、删、改、查；撤销/修改后按交易重放法重建持仓，保证一致性；卖出超量自动拒绝
- 每次录入/修改/撤销自动重算**当日综合评分**

**行情与数据（缓存优先，动态/静态分流）**
- **动态数据**（每次刷新更新）：分钟级实时价格、当日涨跌；实时市值 = 实时股价 × 总股本（总股本来自雪球 reg_asset，静态慢变量）
- **实时估值**（市值/TTM 口径）：实时 PE = 市值/TTM净利（TTM = 去年年报 + 今年最新累计 − 去年同期累计）、实时 PB = 市值/归母净资产、股息率 = 去年净利×支付率/市值
- **前瞻指标**（同比增速 g 递推）：前瞻 PE/PB = 实时值/(1+g)、前瞻股息率 = 股息率×(1+g)
- **静态数据**（全量刷新才更新）：财务（多期归母净利、归母净资产、总股本、EPS、去年股息支付率）、百度 PE/PB 历史序列（1y/3y/5y）与分位
- 收盘定格：收盘后首刷定格当日价格，二次刷新零重复请求

**单股分析**
- PE/PB 实时值 + 1y/3y/5y 分位、前瞻 PE/PB 及前瞻分位
- **PE/PB 近三年历史折线图**（百度序列直接画），图上标注实时值/前瞻值及各自分位
- 全天五档资金流（主力/超大/大/中/小单净流入）
- 财务指标（去年净利/净资产/支付率/净利同比）与股息率
- 15 分钟资金流：暂无可用数据源，界面占位（后续接入）

**组合分析（自建 ETF 视角）**
- 综合 PE/PB（指数式市值加权，亏损股允许参与）、综合估值分位（折线图可拖动缩放切换分位窗口）
- 综合股息率、综合 ROE、综合营收/净利增长率、年化波动率
- 权重分布（市值口径）、逐股贡献

**评分模型**
- 买入 / 卖出各六因子 0-100 分，评级 A/B/C/D
- **当日所有交易按成交金额加权平均**得到当日综合评分，可回看历史
- 因子权重存数据库，可通过 API 调整

**前端**
- 四个页面：持仓总览 / 组合分析 / 个股 / 交易评分，原生 JS + ECharts，无构建步骤

## 核心逻辑

### 数据层：缓存优先 + 手动刷新（动态/静态分流）

**设计原则（读零网络）**：所有 GET 读接口只读缓存，绝不触发网络。唯一的写数据入口是右上角刷新按钮。

```
刷新按钮 ──► 拉取数据 ──► 写缓存表（按天/按报告期 upsert）──► 页面读缓存渲染
   ▲                                                          ▲
   │                                                          │
   └────── 唯一网络入口                                GET 全部零网络 ┘
```

**动态 vs 静态**（两个刷新按钮，分工不同）：

| 数据 | 刷新频次 | 来源 |
|---|---|---|
| 实时股价 / 实时市值 / 实时 PE/PB / 股息率 | 每次「⚡动态刷新」 | 分钟级行情（新浪）+ 总股本（雪球）+ 归母净资产本地计算 |
| 财务（多期净利 / 归母净资产 / 总股本 / EPS / 支付率） | 每次「🔄全量刷新」 | 新浪财务摘要 + 雪球 + 巨潮分红 |
| 百度 PE/PB 历史序列（1y/3y/5y）与分位 | 每次「🔄全量刷新」 | 百度序列，缓存后画折线图 |

实时市值、PE/PB、股息率**在读取时本地现算**（股价×总股本/TTM），不依赖缓存快照；动态刷新只更新价格与当日估值快照，不碰静态数据。总股本取雪球 `reg_asset`，归母净资产 = 每股净资产 × 总股本。支付率 = **去年全部分红（含中期+末期）** / 去年 EPS。

- **收盘定格**：交易日 15:00+5 分钟视为已收盘。收盘后首次刷新把当日价格定格（`is_closed=1`）；再刷新直接跳过，零重复请求。
- **盘中**：刷新写入当日实时快照（`is_closed=0`），页面读到即盘中价。
- **增量**：日K 只拉「上次缓存日期+1 ~ 今天」；估值分位/财务按计算日/报告期缓存命中即跳。
- **读兜底**：当日无数据时回退最近一条缓存并标 `stale:true`，前端提示「请先刷新」。
- **降级**：数据源失败时单只股票跳过、不中断整体；`GET /api/status` 实时探活各源。

### 持仓与交易

- **移动加权成本**（事务内）：`新成本 = (旧数量×旧成本 + 金额 + 费用) / 新数量`；卖出只减数量、成本不变；数量归零转 `closed`。
- **重放法一致性**：持仓是交易记录的物化视图。每次增/删/改后，对受影响股票按时间顺序重放全部交易重算持仓——绝对一致，撤销只需删交易再重放；若重放出现「卖出超过持仓」则拒绝并回滚。
- **交易字段**：`code, side(buy/sell), price, quantity, amount, fee, trade_time, note`。数据库有唯一约束 `(code, trade_time, side, price, quantity)` 防重复。

### 当日综合评分模型

**每笔交易**先按方向算因子分（0-100），缺失因子（如资金流暂无数据）不参与，总分按**已用因子权重**归一化：

**买入** `Σ weight×score / Σ weight(used)`：

| 因子 | 权重(默认) | 得分公式 | 语义 |
|---|---|---|---|
| PE 分位(1y) | 25% | `100 - pe_pct` | 分位越低越便宜 |
| PB 分位(1y) | 20% | `100 - pb_pct` | 同上 |
| 股息率 | 15% | `min(100, dv/4×100)` | 股息 4% 满分 |
| 主力资金 | 15% | `clamp(50 + main_net_pct×10)` | 净流入得分高 |
| 当日涨跌 | 10% | `clamp(100 - pct_chg×10)` | 回踩买点得分高 |
| ROE | 15% | `min(100, roe/15×100)` | ROE 15% 满分 |

**卖出**：

| 因子 | 权重(默认) | 得分公式 | 语义 |
|---|---|---|---|
| PE 分位(1y) | 25% | `pe_pct` | 分位越高越该卖 |
| PB 分位(1y) | 20% | `pb_pct` | 同上 |
| 股息率 | 10% | `100 - min(100, dv/4×100)` | 股息越低越该卖 |
| 主力资金 | 15% | `clamp(50 - main_net_pct×10)` | 净流出得分高 |
| 当日涨跌 | 10% | `clamp(pct_chg×10)` | 涨幅大得分高 |
| 组合集中度 | 20% | `min(100, w/20×100)` | 仓位>20% 该减仓 |

**当日综合分**（用户确认口径）：`综合分 = Σ(单笔分 × 成交金额) / Σ成交金额`（金额加权平均），每日一条存 `daily_scores`。交易增/删/改后自动重算该日；刷新数据后重建全部有交易日的综合分。

**评级**：≥85 A（优秀）/ 70-85 B（良好）/ 55-70 C（一般）/ <55 D（较差）。

**权重可调**：`GET /api/scoring/rules` 查看，`PUT /api/scoring/rules` 修改（权重和须为 1，存 `config` 表，已配置则完全覆盖默认）。

### 组合分析算法

统一用**持仓市值权重** `w_i = quantity×现价_i / Σ(quantity×现价)`（自建 ETF 看自身资金暴露）。

| 指标 | 公式 |
|---|---|
| 综合 PE / PB（指数式） | `总PE = Σ市值 / Σ(市值/PE)`，即 `1/总PE = Σw_i/PE_i`；亏损股允许参与（总盈利≈0 标不适用），缺数据的股票用其最近有效值填充 |
| 综合分位 | `Σw_i × pct_i`（剔除不适用并归一化权重） |
| 综合股息率 | `Σ(市值×股息率) / Σ市值` |
| 综合 ROE / 增长率 | `Σw_i × roe_i` 市值加权（报告期错位会在页面标注） |
| 年化波动率 | N=250 交易日，`R_t = Σw_i·r_{i,t}`，`σ = std(R_t, ddof=1) × √250` |

原料按天缓存，组合指标读取时实时计算；缺数据的股票临时剔除并在响应 `missing` 标注。

## API 一览

统一响应 `{ok, data}`，错误返回 HTTP 4xx/5xx + `detail`。全部前缀 `/api`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/status` | 服务状态 + 数据源探活 |
| POST | `/refresh` | **动态刷新**：价格 + 当前 PE/PB |
| POST | `/refresh/full` | **全量刷新**：日K + 分位重算 + 财务 |
| GET | `/holdings` | 持仓列表（`?active=`） |
| POST | `/holdings` | 批量初始化 `{items:[{code,name,price,quantity,fee}]}` |
| POST | `/trades` | 录入交易 → 持仓 + 当日综合分 |
| GET | `/trades` | 交易流水（`?code=` 筛单股） |
| PUT | `/trades/{id}` | 修改交易 → 重放持仓 + 重算评分 |
| DELETE | `/trades/{id}` | 撤销交易（回滚持仓） |
| GET | `/stocks/search?q=` | A 股代码/名称搜索 |
| GET | `/stocks/{code}` | 单股全套：行情/实时估值(live)/前瞻/分位/历史序列/财务/资金流 |
| GET | `/portfolio` | 组合整体 + 逐股（`?code=` 查单股贡献） |
| GET | `/portfolio/weights` | 权重分布 |
| GET | `/scoring/rules` | 评分权重与因子说明 |
| PUT | `/scoring/rules` | 更新评分权重 |
| GET | `/scoring/daily?date=` | 某日综合评分（默认最近） |
| GET | `/scoring/history` | 每日综合评分历史 |

## 数据库表

| `fundflow_15m_cache` | 15 分钟资金流（暂未填充） |

| `daily_scores` | 每日综合评分（含因子与每笔明细） |
| `config` | 评分权重等可配置项 |
| `trade_calendar` | 交易日历 |

## 已知限制

- **仅 A 股**：港股/美股后续版本。
- **15 分钟资金流**：无可用数据源，界面占位；评分中「主力资金」因子因无数据自动归一化（不影响其他因子）。
- **数据源依赖**：行情/财务走新浪，总股本走雪球，估值分位走百度；东财行情接口在本网络环境不可达，已放弃。若某源临时失败，对应数据跳过、整体刷新不中断。
- **昨收/涨跌幅**：日K 缓存含 `pct_change`（刷新时计算）；历史早期无昨收的交易日涨跌幅可能为空。
- **ECharts 走 CDN**（jsdelivr）：离线环境图表不渲染，其余功能正常；可将 `echarts.min.js` 下载至 `static/js/` 并改引用来完全离线。
